Questions

Frequently asked

Do I need to create an account?

No. There is no login, no signup and no paywall. Open the page and start validating numbers immediately.

What format should I enter the number in?

International (E.164) format works best — the country code with or without a leading +, for example +14158586273. If you prefer, choose a country from the dropdown and type the local number; the dialling prefix is added for you.

What does “line type” mean?

It is the class of service the number belongs to: mobile, landline, voip, toll_free, premium_rate, satellite, paging or special_services. It is the fastest way to tell whether a number can receive SMS.

Why is the carrier or location field sometimes empty?

Coverage depends on what each country's numbering plan publishes. Landlines in many countries expose a region but no carrier; some mobile ranges expose a carrier but no city. An empty field means “not published”, not “invalid”.

Does the DNC check tell me if a number is on the Do Not Call Registry?

No. The National Do Not Call Registry — the list of consumers who opted out of telemarketing — has no public API. Telemarketers reach it by registering at telemarketing.donotcall.gov for an Organization ID and SAN and downloading per-area-code lists; consumers check their own number at donotcall.gov. What this site queries is a different FTC dataset: consumer complaints about unwanted calls. It answers “has this number been reported for robocalls”, not “is this number registered”.

Can I use the DNC check for telemarketing compliance?

No — it is not a substitute for scrubbing against the registry, and using it that way would leave you exposed. Complaint data is a reputation signal: useful for spotting known robocallers, screening inbound calls, or checking what a number is already associated with. Lawful outbound calling still requires a registry subscription.

Is my data stored?

This site has no backend. Lookups go straight from your browser to the validation API, and your recent-lookup history lives only in your own browser's local storage. Clearing it removes it for good.

Can I use my own API key?

Yes. Open and paste your own numverify access key — it is saved in your browser only and takes priority over the built-in demo key.
