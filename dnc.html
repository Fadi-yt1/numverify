What this checks — and what it doesn't

Is this the National Do Not Call Registry?

No. The registry — the list of consumers who opted out of telemarketing — has no public API. Telemarketers reach it by registering at telemarketing.donotcall.gov for an Organization ID and SAN; consumers check their own number at donotcall.gov. This page queries a different FTC dataset: consumer complaints about unwanted calls. It is a reputation signal, not a compliance scrub, and it will not make outbound telemarketing lawful.

Why does it search by area code instead of the number?

Because the FTC API cannot be filtered by the number that placed the call. Its filters are the created date, state, area code and a robocall flag; the caller's number comes back as a field, never a search key. So the check pulls a recent window of complaints from the number's own area code — up to 50 records, the endpoint's cap — and looks for the number among them.

What does “not found” actually mean?

That the number was absent from that sample, and nothing more. The FTC receives hundreds of thousands of complaints a month nationwide, so 50 records from one area code is a thin slice. A hit is strong evidence; a miss is weak evidence, not a clean bill of health.

Where is the database stored?

In your browser, using IndexedDB (or localStorage if IndexedDB is unavailable, as in some private windows). It never leaves your machine, is not shared with other people or your other devices, and disappears if you clear the site's data. Use Export to move it somewhere durable.

Can I use my own API key?

Yes — open and paste an api.data.gov key. It is stored in this browser and takes priority over the bundled demo key.
